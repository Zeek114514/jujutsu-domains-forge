# 无下限术式：苍、赫、虚式·茈

默认按键可在设置中修改。三种术式分别冷却，K同时重置它们的冷却和领域熔断。需要客户端和服务端同步安装1.5.0；无下限同步通道升级为协议2。

| 按键 | 术式 | 行为 |
| --- | --- | --- |
| Z | 苍 | 点按短蓄力发射；按住最多2秒增强，松开后发射 |
| X | 赫 | 约1秒蓄力，发射后爆发斥力并击飞目标 |
| C | 虚式·茈 | 约3.5秒演出，苍赫从两侧靠拢汇合，再向前发射 |
| K | 重置 | 重置领域熔断与苍、赫、茈的独立冷却 |

苍最远40格，落点上方悬浮约4秒并持续吸引周围目标；吸引范围随蓄力从8格提高至12格，每半秒造成4至6点基础伤害，冷却5秒。蓄力达到上限会自动发射。

赫最远64格，爆发半径6格，中心最高72点基础伤害，向边缘衰减，并产生强烈击退，冷却6秒。

茈最远96格，沿途以约4.5格半径检测目标，每个目标每次施放最多命中一次，基础伤害160点，冷却15秒。伤害经过Minecraft和Forge伤害事件，实际承伤受目标防御等因素影响。

三种术式保护施术者、队友及自己的可驯服宠物，完整外部无量空处的庇护也会生效。持续存在的苍不占用下一次术式的蓄力手势；正在蓄力时不能同时蓄力另一个术式或灶·开。领域咏唱期间不能开始蓄力。方向在发射时确定。

## 空中组合：自爆茈

1. 向空中射出苍（Z）或赫（X）。在无障碍的空中，苍飞至约40格后停留；单独的赫约32格后停留，均最多约8秒。地面落点仍走原来的吸引/斥力逻辑。
2. 瞄准那颗能量球，射出相反属性。两种顺序都支持，仅同一施术者的苍与赫可以融合。赫在前方存在可命中的苍时会继续飞行，保留原有64格射程；不会为此穿过墙壁或自动修正瞄准。
3. 相撞后消耗两颗球，在碰撞位置形成茈，用约2.2秒逐渐膨胀，随后爆炸。C键原有直射茈仍可使用；融合时刷新茈的15秒冷却，K仍可重置。

默认冲击波半径64格，中心基础伤害480点，边缘120点；每个目标每次爆炸最多命中一次。施术者也会受反噬，伤害为同位置普通目标的5%；创造与旁观保持保护。队友、自己的宠物、完整外部无量空处结界以及普通实心墙体能提供对应保护。实际承伤仍经过Minecraft/Forge伤害流程。

膨胀阶段死亡、旁观或离开维度会取消；爆炸已经开始后，不会因施术者死亡或切换旁观而收回正在扩散的伤害波。退出服务器、换维度仍清理所有本人的术式状态。只结算已加载区域，不生成新区块。

`config/unlimitedvoid-common.toml`可调整：

```toml
purpleDetonationRadius = 64.0
purpleDetonationDamage = 480.0
purpleDetonationBacklash = 0.05
```

反噬比例设为0可保护施术者。爆炸伤害范围与主冲击波采用服务端同步的同一个半径；边缘光晕是演出。自爆茈沿用`limitlessTerrainDamage = false`，默认保留地形。手动开启时按预算分散破坏，不是一次性清空整个球体。

融合使用现有茈的聚能与命中音效，不重复播放C键直射时的整句出招台词。[本版实机与同步验证](PURPLE_DETONATION_VALIDATION.md)。

## 演出

使用原版方块手臂和玩家皮肤。单独的苍显示白色亮核和青蓝色不规则火焰，赫显示紧凑红球、亮核与火花。茈蓄力时，两颗深蓝、暗红的流动云纹球从两侧靠拢，接触并淡出，生成带星点、白粉亮核、跳动闪电的紫色球体和拖尾。球体周围会折射背景，受到地形与手臂遮挡。近距离发射会降低施术者面前光晕的不透明度。

折射是客户端视觉效果，不会移动方块。实机画面与已验证的光影组合见[1.4.0验证](LIMITLESS_ORBS_VALIDATION.md)。

1.3.1使用网上搜集的日语短呼号与效果声，每种术式分成语音、蓄力、发射和命中四个事件。茈按用户明确选择，所有声音均来自[Hollow Purple](https://www.myinstants.com/en/instant/hollow-purple-6717/)同一片段，语音在融合过程中触发。进入飞行不会截断已开始的短句，正常消散后保留短暂余响，取消或退出时停止。素材来源、裁剪与权利说明见[音频记录](../requested_limitless/README.md)，不是MIT或CC0录音。

## 地形与限制

默认不破坏方块，茈碰到实心方块会停止。`config/unlimitedvoid-common.toml`中的独立选项：

```toml
limitlessTerrainDamage = false
```

手动设为true允许茈局部破坏沿途方块；每次推进最多检查125个位置、破坏16块，不产生掉落物。不破坏基岩、液体和方块实体，并经过Forge方块破坏事件。该开关和御厨子的地形破坏开关独立。

最多同时8个术式演出，球体渲染每帧最多32张代理四边形，折射颜色缓存最长边不超过1280×720；深度按当前视口保存。逐球从后向前更新背景缓存，避免融合交界被错误挖空。代理数量不等于GPU开销保证；分辨率、覆盖面积和光影影响实际性能。每轮最多处理128个生物候选，茈每次施放最多伤害512个唯一目标。只访问已加载区域，不为射线生成新区块。普通术式的死亡、旁观与离开清理保持原规则；自爆茈已经开始扩散时按上文处理。
