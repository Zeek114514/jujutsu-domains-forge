# 1.12.0 玩法更新

按用户要求依次完成战斗AI、状态显示、NPC管理、生存成长，再进行双客户端和群战验收。

## 使用

- 瞄准24格内无遮挡的角色：显示生命、形态、动作/战斗/领域状态；魔虚罗显示适应类别。
- 潜行右键NPC：角色管理。创造模式或管理员可设置跟随、待命、自由行动、红蓝/默认阵营、攻击最近敌人。手动跟随/待命会解除当前拴绳并优先于自动互动。
- 对战：给32格内的战斗NPC分配红蓝双方，点击开始。最多24个参与者；保存开始前的身份、位置、血量和行为，重置恢复。只恢复本次会话参与者，区块未加载时会要求先靠近。快照随玩家保存并在死亡克隆时保留。
- 召唤魔虚罗默认继承召唤者的自定义阵营；召唤者待命或跟随时停止主动战斗，仍可跟随召唤者。
- [P]打开术式成长页，并切换火焰特效质量（完整/均衡/省电）。质量只影响客户端火焰粒子，不改变服务端伤害。

## 战斗AI

有视线时观察对手前摇，概率侧移；拥有反转术式的低血量角色会尝试撤步，看到硬直破绽时追击。五条的侧移距离/频率更高，宿傩偏重接近追击。使用正常寻路，不瞬移；侧移和撤步检查落点支撑、流体和碰撞，不强制加载区块。原有特殊贴脸茈、濒死变身、领域反开与魔虚罗成长保留。

## 生存成长

默认启用 `survivalProgression=true`，创造模式可直接使用全部能力。生存玩家潜行持眼罩或宿傩手指在空中右键，消耗一个物品选择路线。当前为一次路线选择，成长随玩家保存并在死亡后继承。

- 眼罩配方：上排3个黑色羊毛，下一排左右各1根线。
- 手指配方：上中、左中、右中各1块腐肉，中间骨头，下中金粒。
- 获得黑色羊毛/骨头会解锁对应配方书条目。
- 成功施术获得2熟练度；击败敌对怪物获得12熟练度。每40熟练度提升一级，最高20级。
- 咒力上限100～195，每秒恢复2点。死亡不直接补满咒力，切换创造模式不消耗咒力。

## 多人和性能

客户端/服务端均需1.12.0，无下限协议9、领域协议14，新增管理/成长通道各为1。修改角色需要创造模式或管理员权限，普通生存客户端无法越权。管理动作有距离、视线和频率限制，状态查看与修改请求分别限流。

完整/均衡/省电火焰粒子上限分别为4500/2250/900，每tick新建上限300/150/60，远处粒子裁剪距离768/256/128。降低档位会清理超出新上限的粒子。
