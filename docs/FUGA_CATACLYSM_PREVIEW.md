# 灶·开：核爆规模粒子演示

在 1.12.0 本地版本上重做客户端粒子效果。保留现有火弓、火箭、施放音轨和服务端伤害规则；不扩大真实伤害，不自动开启地形破坏。

## 视觉结构

- 命中后先出现短暂白金色爆心，再快速升起白热火柱。
- 高空烟冠沿环形向外翻卷，明亮下沿与深色灰烬外壳形成轮廓。
- 地面依次传播两圈冲击前沿，伴随大面积着火粒子、扬尘和上升余烬。
- 尾段降低粒子透明度，并限制寿命在术式结束之前，避免结束时整团突然消失。
- 高度 240 格、地面火焰半径 200 格、冲击波半径 300 格沿用原视觉参数；通过结构、速度和颜色强化规模感。
- 完整/均衡/省电质量继续分别受 300/150/60 每 tick 和 4500/2250/900 存活粒子上限约束，低质量按比例分配各层，防止只有火柱而缺失烟冠。
- 两张原有程序生成的粒子遮罩升至 128×128，以减少大型粒子的锯齿。没有复制动画或漫画图像作为游戏资产。

## 可复现演示

使用 `-PvisualTest=true jar` 生成测试包，通过 `tools/run_fuga_qa.py --suite particles --mode plain --width 1280 --height 720 --run-id <新的标识> --test-jar <指定测试包>` 启动一次性独立世界。原版方块组成的建筑提供尺寸参照，实际客户端向集成服务器请求施法，截图不是离线绘制。

录制 216 张连续帧，以 20 fps 编码为 10.8 秒 H.264/AAC MP4。`tools/encode_fuga_preview.py` 检查帧序列完整性并解码检查输出。测试客户端使用无输出音频设备，视频声音由模组现有语音、发射和命中音轨按施法时序混合，不是系统音频录制。未使用光影包或后期发光滤镜。

测试在视频录制之后再次真实施法，检查存活粒子大于零、峰值不超过 4500，再执行所有者清理并断言无残留。该演示不是多人或所有硬件性能验收。

## 超大火焰弓的轮廓修订

用户希望保留超大尺寸，改进成形和质感。蓄力弓身现在约 6.9 格高，箭长约 5.5 格，以白热细芯、橙色外焰、明确的拉弦和立体箭头组成；火舌沿弓臂向两端流动。去掉遮挡武器轮廓的 18 格范围随机聚火云，仅保留朝握持处汇入的局部火流。命中后的核爆式特效不变。

连续发光的弓身与粒子火舌叠加，避免点状粒子形成“珠串”。弓臂略向侧面展开，第一人称也可读出弯曲形状。世界深度遮挡保留；单帧几何最多 4096 个四边形，并恢复渲染前的 shader、颜色、混合、深度和剔除状态。三档粒子质量均按比例保留弓身、弦、箭头和局部火流。
