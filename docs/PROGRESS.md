# 开发进度

更新日期：2026-10-29。当前本地版本 **1.10.4**，GitHub正式版1.10.0。本次将1.6～1.10的本地开发成果汇总同步到GitHub；下列旧版本条目保留其当时状态。

1.10.4按更清楚的参考图将光滑角改为两对分层羽翼，轮盘改为竖向朝前并增加弯曲头冠、腰后飘带、环状垂饰和黑裤；保持4格高的站立比例。[本轮验证](MAHORAGA_FEATHERS_VALIDATION.md)。

1.10.3按用户参考图重做两对上弯长角及V形链纹，拉长腿和躯干，基础身体与碰撞高度4格，眼高3.5格，保留原头宽和肩宽。[本轮验证](MAHORAGA_REFERENCE_VALIDATION.md)。

1.10.2收窄腰腹、裤型与手臂，保留宽肩胸背；取消成长上限，抗性满级后仍可通过重复命中继续成长。独立长整数成长计数保存/同步，无下限协议7。[本轮验证](MAHORAGA_GROWTH_VALIDATION.md)。

1.10.1细化魔虚罗肌肉、骨骼、侧鳍、剑刃及轮盘，适应阶段累计使体型每次增加5%（当时最高2.6倍）；高专觉醒与惠皮原身变身改为默认50%且一生只判定一次，失败状态保存。[本轮验证](MAHORAGA_REFINEMENT_VALIDATION.md)。

1.10.0加入魔虚罗实体、专用立体模型、影池召唤/退场、独立战斗、八类逐步适应与八握轮转动，惠皮召唤接口现已接通。保留1.9.1宿傩与战力修复；创造栏共九项，无下限协议6。见[魔虚罗指南](MAHORAGA.md)和[本版验证](MAHORAGA_VALIDATION.md)。

1.9.1修复宿傩的近身延展、无量空处内行动、开放领域外侧破壳和走下神龛继续战斗；实测记录见[NPC战斗平衡修复](NPC_BALANCE_VALIDATION.md)。

1.9.0加入NPC领域反开/同类去重、三种宿傩近战/斩击/灶·开、惠皮形态和濒死满血原身。魔虚罗仅预留召唤接口，本体后续制作。领域协议14/无下限协议5。验证见[NPC领域记录](NPC_DOMAINS_VALIDATION.md)。

1.8.1改为五条快速追击、苍拳/赫拳近身为主，降低常规远程频率；高专只苍拳，特殊觉醒/茈规则保留。无下限协议4。

1.8.0加入觉醒五条、濒死回血变身、五条战斗AI、贴脸茈、一次性自爆、五形态生命升级与反转术式。旧NPC血量按比例迁移，界面右键可看血量。无下限协议3；本地验证见[NPC战斗记录](NPC_COMBAT_VALIDATION.md)。

1.7.2新增新宿五条和原身宿傩的独立生成蛋，直接生成最终形态，保留旧变身路线。创造栏现在共六个物品。

1.7.1新增独立创造模式栏，移出原版分类；加入五条默认被动“无限”，阻挡普通近战与投射物、减速来袭投射物。仍无自动攻击，例外及配置见[NPC说明](NPCS.md)。

1.7.0按最新要求改为用户提供的原版玩家皮肤、服装定点修改与右键物品变身，退役自制立体发型和配件。旧实体ID保留。详见[NPC说明](NPCS.md)。

1.6.1曾针对精细度不足重做NPC模型和256×256图集，增加多段发束、阶梯墨镜、衣领/兜帽/袖口/鞋子结构，细化咒纹。保留生成方式和展示行为。

1.6.0新增高专五条悟和16指虎皮宿傩展示NPC、两种生成蛋、原创像素皮肤、方块发束和墨镜。暂不自动战斗或释放术式，支持实体保存。见[NPC说明](NPCS.md)。
