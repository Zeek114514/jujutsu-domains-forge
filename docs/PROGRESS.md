# 开发进度

更新日期：2026-10-28。当前本地版本 **1.6.1**，GitHub公开版仍为1.5.1。

1.6.1针对精细度不足重做NPC模型和256×256图集，增加多段发束、阶梯墨镜、衣领/兜帽/袖口/鞋子结构，细化咒纹。保留生成方式和展示行为。

1.6.0新增高专五条悟和16指虎皮宿傩展示NPC、两种生成蛋、原创像素皮肤、方块发束和墨镜。暂不自动战斗或释放术式，支持实体保存。见[NPC说明](NPCS.md)。

1.5.1将灶·开粒子预览合入并默认启用，修复此前未装入正式包的遗漏。每客户端4500粒子/每tick新建300上限，保留原伤害与音效。

1.5.0加入空中自爆茈：苍/赫停留、双向碰撞融合、膨胀与球形冲击波、范围伤害和可配置反噬。无下限同步通道升级为协议2，客户端与服务端需共同更新。[机制](LIMITLESS.md) · [验证范围](PURPLE_DETONATION_VALIDATION.md)。

1.4.1将获确认的解与捌斩痕样式合入正式版：两端收尖的白刃、红黑裂痕、掠动与目标附近的三道交叉斩击。沿用原有伤害、咒力与音效。[斩击验证](SHRINE_SLASH_VALIDATION.md)。当时的灶·开粒子保留为独立预览，直到1.5.1才合入。

1.4.0重做苍、赫和虚式·茈的视觉：单独术式的亮核/火焰/火花、融合时深色云纹球、茈的紫色体积与闪电，加入曲面折射与深度遮挡。绘制移到世界光影合成之后、界面之前。见[画面与验证](LIMITLESS_ORBS_VALIDATION.md)。

1.3.1将苍、赫、茈的合成声音替换为网上搜集的日语短呼号和分阶段效果声；茈采用用户指定的单一音源。见[音频来源](../requested_limitless/README.md)和[本版验证](LIMITLESS_AUDIO_VALIDATION.md)。

1.3.0加入苍、赫、虚式·茈：服务端伤害与运动、按住蓄力、苍赫融合演出、原版方块手臂、独立冷却、自制合成音效和独立的茈地形开关。见[指南](LIMITLESS.md)和[本版验证](LIMITLESS_VALIDATION.md)。

1.2.1将领域手势改为原版方块手臂，去掉独立手指与额外手掌模型。显示修正见[本版验证](VANILLA_SEALS_VALIDATION.md)。

1.2.0将灶·开的默认伤害半径扩展至200格，中心伤害提高至240点、粉尘强化480点，并加入自动随咏唱抬起和放下的第一、第三人称领域结印。
