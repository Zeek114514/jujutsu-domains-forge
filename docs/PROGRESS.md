# 开发进度

更新日期：2026-10-27。当前版本 **1.3.1**。

1.3.1将苍、赫、茈的合成声音替换为网上搜集的日语短呼号和分阶段效果声；茈采用用户指定的单一音源。见[音频来源](../requested_limitless/README.md)和[本版验证](LIMITLESS_AUDIO_VALIDATION.md)。

1.3.0加入苍、赫、虚式·茈：服务端伤害与运动、按住蓄力、苍赫融合演出、原版方块手臂、独立冷却、自制合成音效和独立的茈地形开关。见[指南](LIMITLESS.md)和[本版验证](LIMITLESS_VALIDATION.md)。

1.2.1将领域手势改为原版方块手臂，去掉独立手指与额外手掌模型。显示修正见[本版验证](VANILLA_SEALS_VALIDATION.md)。

1.2.0将灶·开的默认伤害半径扩展至200格，中心伤害提高至240点、粉尘强化480点，并加入自动随咏唱抬起和放下的第一、第三人称领域结印。

本轮验证见[1.2.0验证记录](DOMAIN_SEALS_VALIDATION.md)。下表保留1.1.0的既有功能与验证范围；没有将旧版完整联网/并发测试表述为本版重新执行。
