# 角色、战斗与反转术式 · 1.8.0

本版使用用户提供的五张64×64皮肤及原版玩家模型，保留正确的经典/纤细手臂和外层，不使用已撤回的自制立体发型。

## 血量与招式

数值为生命值，不是心数。空手右键角色可查看当前/最大生命。

| 角色 | 最大生命 | 普通攻击术式 | 反转术式 |
| --- | ---: | --- | --- |
| 高专五条 | 400 | 只用苍 | 不使用；首次濒死触发觉醒 |
| 觉醒五条 | 800 | 苍50%、赫45%、茈5% | 每2秒回复4点 |
| 新宿五条 | 1000 | 苍50%、赫45%、茈5% | 每2秒回复5点 |
| 虎皮宿傩 | 800 | 本轮未加主动攻击 | 每2秒回复4点 |
| 原身宿傩 | 1000 | 本轮未加主动攻击 | 每2秒回复5点 |

这些最大生命均在原版属性1024上限内。旧版40血NPC在加载时按原生命比例迁移，旧满血角色升级后满血，旧半血角色仍为半血，不复活已死实体。普通物品变身保持血量比例；首次觉醒例外为直接回满觉醒形态。

### 五条的自动战斗

五条在附近寻找可见的怪物与原身宿傩，不主动攻击玩家、宠物、普通生物、其他五条或尚未变身的虎皮宿傩。阵营同队保护有效。常规技能选择在服务器进行，觉醒/新宿的茈为每次选择5%，不是每tick5%。使用既有苍/赫/茈球体、飞行、命中视觉和分阶段声音，普通术式有蓄力与冷却。

新宿遇到原身宿傩（包括由虎皮交付手指变成的形态）会优先接近至约1.8格，直接发射茈，不走普通随机选择与蓄力。会尝试寻路，不穿墙传送；无法到达或没有视线时不会隔墙贴脸攻击。

### 濒死优先级

- 高专生命低于最大值5%，或一次非绕过伤害将使其低于5%/致死：优先变为觉醒五条，满血800，立刻发射一次茈。保留实体UUID，觉醒与首发状态随NBT保存。不会同时自爆，也不会反复觉醒刷满血。
- 觉醒/新宿存活且低于5%：触发一次自爆茈。先膨胀约2.2秒，再按已有自爆参数扩散，默认半径64格、中心480基础伤害、5%施术者反噬。每个NPC终生一次，状态保存，变身/重载不重置。
- 自爆蓄力阶段被杀死或卸载会取消；爆炸已开始后即使反噬致死仍继续扩散。若低血施术者活下来，结束后可恢复反转术式，不会一直锁在低血状态。
- `/kill`等绕过伤害仍能移除高专五条，不触发免死觉醒。

NPC伤害只结算怪物/原身宿傩及自爆时施术者反噬，保护玩家和普通友方生物，尊重墙体和外部完整无量空处庇护。本版NPC术式不破坏地形。

### 反转术式

觉醒、新宿和两种宿傩均可使用；受到实际伤害后等待3秒，再每2秒回复最大生命0.5%，出现少量淡粉粒子，满血停止，再受伤会重新等待。被无限完全挡住的攻击不计实际受伤。高专没有普通回血。回血延迟随NBT保留。

濒死觉醒/自爆优先于普通回血；自爆存活且一次性触发已用掉后，允许重新回血。`NoAI`会关闭主动战斗和反转回血，方便静态展示；无限仍为被动。

## 获取与物品变身

【咒术领域】创造栏现有五种生成蛋、眼罩和宿傩手指，共七个物品。可直接生成任意形态：

```mcfunction
/give @s unlimitedvoid:student_gojo_spawn_egg
/give @s unlimitedvoid:awakened_gojo_spawn_egg
/give @s unlimitedvoid:shinjuku_gojo_spawn_egg
/give @s unlimitedvoid:sukuna_16_spawn_egg
/give @s unlimitedvoid:true_sukuna_spawn_egg
/give @s unlimitedvoid:blindfold
/give @s unlimitedvoid:sukuna_finger
```

高专或觉醒五条手持眼罩右键可变成新宿，虎皮宿傩交付手指变成原身。生存初次交付消耗一个，创造不消耗；已完成对应变身后重复交付不消耗。原有实体ID与旧存档兼容，新增觉醒实体ID为`unlimitedvoid:awakened_gojo`。

五条各形态默认具备“无限”：普通近战/投射物伤害阻挡、靠近投射物减速。环境、领域必中、非投射物魔法及绕过伤害不统一免疫。`gojoInfinity=false`可关闭。

## 同步、性能与保存

NPC与玩家共用最多8个正在运行的术式，达到上限时等待空位；觉醒首发待发状态会保留。目标扫描、每tick伤害处理和每次命中数量均有上限；不强制加载区块。角色卸载会中断非爆炸阶段术式，施法本身不跨服务端重启保存。

无下限通道升级为协议3，服务端与客户端均须更新1.8.0。旧玩家施法仍保留原来的按键、冷却、音效和伤害逻辑。
