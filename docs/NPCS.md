# 角色、战斗与反转术式 · 1.10.0

本版使用用户提供的六张64×64皮肤及原版玩家模型，保留正确的经典/纤细手臂和外层，不使用已撤回的自制立体发型。

## 形态战力基准

按当前形态调整为：高专五条 < 觉醒五条 < 虎皮宿傩 < 新宿五条 ≈ 新宿宿傩（惠皮） ≤ 原身宿傩。保持原生命上限，通过输出、承伤、速度和招式组合拉开差距；不在AI里写死谁必须获胜。高专觉醒后按觉醒形态计算，惠皮变原身后按原身计算。

| 当前形态 | 输出倍率 | 承伤倍率 | 基础移速 |
| --- | ---: | ---: | ---: |
| 高专五条 | 0.85 | 1.10 | 0.34 |
| 觉醒五条 | 1.00 | 1.00 | 0.34 |
| 虎皮宿傩 | 1.25 | 0.90 | 0.34 |
| 新宿五条 | 1.35 | 0.90 | 0.36 |

倍率用于NPC近战、普通术式和灶·开。玩家技能数值不变；绕过无敌的kill等伤害不减免。新宿五条/惠皮在生命×输出÷承伤的基准上相等，原身更高；实际胜负仍受范围、领域、变身和低概率招式影响。领域捌对这些重要角色采用按形态的伤害，保留实际伤害和压制，不再一次满血处决；普通怪物的原有自适应捌保留。

### 五条的自动战斗

五条快速寻路靠近可见的怪物与敌方宿傩，基础移动速度由0.20提高为0.34。不主动攻击玩家、宠物、普通生物、其他五条；三种敌方宿傩均可成为目标；阵营同队保护有效。

以近身出拳为主：高专只用苍拳；觉醒/新宿在近身拳击中70%苍拳、30%赫拳。苍拳短促吸近，基础18伤害；赫拳基础28伤害并强力击退。约2.3格内起手，3tick后重新检查视线和距离后命中，12tick攻击间隔。可跑出范围躲开；使用原版方块手的出拳动作和少量蓝/红粒子、短音效，不生成术式球或重复完整台词。

首次进入战斗前8秒不放常规远程术式；之后可施法时80%的选择继续拳击，20%尝试远程，远程两次施放至少间隔8秒。进阶远程分支仍为苍50%、赫45%、茈5%，这5%只针对少量远程选择，不是每拳或每tick。高专远程仍只用苍。蓄力时暂停出拳，已存在的苍场不妨碍近身追击。觉醒、贴脸茈和濒死自爆保留更高优先级。

原作中“苍”强化打击的参考见[231话说明](https://comicjiten.com/jujutsukaisen231/)；本版“赫拳”为按用户要求制作的排斥重拳玩法，不作为已核实的原作独立招式名。

新宿遇到原身宿傩（包括由惠皮濒死变成的形态）会优先接近至约1.8格，首次接触该原身目标直接发射茈，不走普通随机选择与蓄力。首发后恢复普通出拳/低概率术式，不每15秒无限重复免费贴脸茈。会尝试寻路，不穿墙传送；无法到达或没有视线时不会隔墙贴脸攻击。

### 宿傩的自动战斗

虎皮、新宿（惠皮）、原身三种宿傩都会寻找敌方五条和怪物，保护玩家、宠物、同队以及其他宿傩。近距离普通拳击基础24伤害（再乘形态倍率），也会发动近距离捌（44）或远程解（28，24格内），使用已确认的白色尖刃与红黑交叉斩痕、现有斩击音效。宿傩基础移速提高到0.34～0.36，追击寻路范围32格。三种宿傩近身会以领域延展突破五条的无限，可进行实际接触攻击；远处普通解仍会被无限挡住，普通怪物与玩家的攻击仍受无限保护。所有攻击继续检查距离、视线和护甲；领域必中仍能攻击无限。

三种宿傩均有极低概率使用原有粒子灶·开，沿用语音、弓姿、火矢、爆燃和配置伤害。NPC版本保护玩家与同方角色，不破坏地形；共用玩家与NPC合计8个灶·开名额，施术者死亡、卸载、NoAI或被无量空处定住会取消。

### NPC领域与反开

所有五条可低概率开无量空处，三种宿傩可低概率开伏魔御厨子。主动领域在接敌约10秒后开始每2秒一次1.5%判定；无敌人不主动展开，常规领域冷却40秒。宿傩的灶·开在同样的稀有判定周期独立0.3%，不是每次普攻或每tick抽取。

同一维度同时仅一个NPC无量空处、一个NPC伏魔御厨子生效，从开始展开便占用名额。对方开始展开时，附近最近且能行动的对应NPC在同一次服务端调用中立即反开，忽略常规随机等待与冷却；NoAI、死亡、被定住、无神龛落脚点或全局8领域名额已满时无法反开。同类已存在领域时不再重复生成。玩家领域的开始展开也会通知附近对应NPC。

领域沿用原有台词、方块手结印、神龛从地面升起、托举、结界、球形范围与淡出。NPC对抗从双方开始展开时就在重叠部分互相抵消必中，避免无量空处较长的形成过程使反开者先被秒杀。独立NPC无量空处会定住普通敌人并持续伤害；三种宿傩仍会受到领域伤害，但不会被定住，可以在结界内继续寻路、攻击和开领域。御厨子开放型必中会伤害敌人，其范围覆盖到结界外侧时会从外削破闭合领域，即使神龛中心位于无量空处内也生效；从实体外壳形成起就能承受斩击。NPC不伤害玩家，但无量空处实体结界仍会限制范围内角色离开。

宿傩在神龛升起、结印结束后会发现地面敌人并走到屋檐外下落继续战斗；不因屋顶遮住视线而一直站在上面。落下阶段不瞬移、不改地形。

领域结束、施术者死亡/卸载/NoAI后按已有40tick过程淡出，释放定身并移除神龛，不在存档里遗留领域。指定光影背景兼容边界见验证记录，不能保证所有光影下的天空与镜面表现。

### 魔虚罗

惠皮宿傩战斗稀有判定周期（每2秒）有1%概率召唤，每名NPC一生最多成功召唤一次。召唤失败不消耗名额。魔虚罗从附近已加载的安全地面影池升起，具备独立战斗、逐步适应与主人退场关联；也可用创造栏专属生成蛋直接生成。规则与限制见[魔虚罗指南](MAHORAGA.md)。

### 濒死优先级

- 高专生命低于最大值5%，或一次非绕过伤害将使其低于5%/致死：优先变为觉醒五条，满血800，立刻发射一次茈。保留实体UUID，觉醒与首发状态随NBT保存。不会同时自爆，也不会反复觉醒刷满血。
- 觉醒/新宿存活且低于5%：触发一次自爆茈。先膨胀约2.2秒，再按已有自爆参数扩散，默认半径64格、中心480基础伤害、5%施术者反噬。每个NPC终生一次，状态保存，变身/重载不重置。
- 自爆蓄力阶段被杀死或卸载会取消；爆炸已开始后即使反噬致死仍继续扩散。若低血施术者活下来，结束后可恢复反转术式，不会一直锁在低血状态。
- `/kill`等绕过伤害仍能移除高专五条，不触发免死觉醒。

新宿宿傩低于5%或非绕过伤害将使其低于5%/致死时，原地满血变为原身宿傩（1000），保留UUID。仅能触发一次，不消耗手指，不会因重复受伤反复回满；`/kill`不触发保命。旧版已存在的原身形态保持原样。

NPC伤害只结算敌方怪物/敌方阵营角色及自爆时施术者反噬，保护玩家和普通友方生物，尊重墙体和外部完整无量空处庇护。本版NPC术式不破坏地形。

### 反转术式

觉醒、新宿和两种宿傩均可使用；受到实际伤害后等待3秒，再每2秒回复最大生命0.5%，出现少量淡粉粒子，满血停止，再受伤会重新等待。被无限完全挡住的攻击不计实际受伤。高专没有普通回血。回血延迟随NBT保留。

濒死觉醒/自爆优先于普通回血；自爆存活且一次性触发已用掉后，允许重新回血。`NoAI`会关闭主动战斗和反转回血，方便静态展示；无限仍为被动。

## 获取与物品变身

【咒术领域】创造栏现有六种生成蛋、眼罩和宿傩手指，共八个物品。可直接生成任意形态：

```mcfunction
/give @s unlimitedvoid:student_gojo_spawn_egg
/give @s unlimitedvoid:awakened_gojo_spawn_egg
/give @s unlimitedvoid:shinjuku_gojo_spawn_egg
/give @s unlimitedvoid:sukuna_16_spawn_egg
/give @s unlimitedvoid:megumi_sukuna_spawn_egg
/give @s unlimitedvoid:true_sukuna_spawn_egg
/give @s unlimitedvoid:blindfold
/give @s unlimitedvoid:sukuna_finger
```

高专或觉醒五条手持眼罩右键可变成新宿，虎皮宿傩交付手指变成新宿（惠皮）；新宿濒死后满血变成原身。生存初次交付消耗一个，创造不消耗；已完成对应变身后重复交付不消耗。原有实体ID与旧存档兼容，觉醒实体ID为`unlimitedvoid:awakened_gojo`，新增惠皮实体ID为`unlimitedvoid:megumi_sukuna`。

五条各形态默认具备“无限”：普通近战/投射物伤害阻挡（宿傩近身延展与领域必中除外）、靠近投射物减速。环境、领域必中、非投射物魔法及绕过伤害不统一免疫。`gojoInfinity=false`可关闭。

## 同步、性能与保存

NPC与玩家共用最多8个正在运行的术式，达到上限时等待空位；觉醒首发待发状态会保留。目标扫描、每tick伤害处理和每次命中数量均有上限；不强制加载区块。角色卸载会中断非爆炸阶段术式，施法本身不跨服务端重启保存。

无下限通道升级为协议5，领域通道协议14，服务端与客户端均须更新1.9.0。旧玩家施法仍保留原来的按键、冷却、音效和伤害逻辑。
