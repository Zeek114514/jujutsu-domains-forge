# 灶·开1.1.0验证记录

记录日期：2026-10-27。JDK17、Minecraft1.20.1、Forge47.4.20实机环境，开发依赖47.4.10。

## 自动规则检查

`build`执行49项时序/边界、15项寻地和83项战斗/渲染预算检查，共147项。它们不启动游戏。正式包另检查不含任何VisualTest或验证入口类。

## 实机与联网

获准后使用独立目录、新建测试世界和离线测试身份运行；没有进入原存档。两个真实客户端通过仅监听127.0.0.1的TCP端口连接，包含Forge握手和模组数据包。

- 普通范围伤害、墙体遮挡、每次施放单次命中、施术者/队友/宠物保护、抗火与关闭伤害开关均通过。
- 自身御厨子积累粉尘、实际命中时消耗、远于普通半径的强化伤害、完整外部无量空处结界保护均通过。
- 第一人称满弦、双臂截图及射出回落已检查。火海取样在洞穴顶棚下正确落到下半砖的实际碰撞面。
- 远端观察者接收到正在进行的演出；通过真实数据包发送晚到和重复状态，验证原开始时间保留、旧射出/命中音效不重播。近落点的施术者发射和命中音效各触发一次。
- 八组同时存在的演出调用实际生产渲染器，检查四边形硬上限；96个存活目标调用实际服务端伤害逻辑，3轮各命中32个不同目标，无重复结算。
- 镜面绘制前后比对实际读/写帧缓冲及视口，验证恢复；额外恢复混合因子。

## 光影与性能

显卡NVIDIA GeForce RTX3060 Laptop GPU、驱动591.59，960×540窗口、视距8、模拟距离5、帧率上限120。Oculus1.8.0 + Embeddium0.3.31 + Complementary Reimagined5.2.2实际启用；通过反射确认IrisRenderingPipeline，不以仅安装模组或回退画面计通过。已目视检查光影下拉弓与并发爆燃截图。

| 采样 | 原版渲染 | 上述光影组合 |
| --- | --- | --- |
| 八组爆燃窗口的平均帧间隔 | 8.59ms | 8.71ms |
| 窗口内最高四边形数 | 3200 | 3200 |
| 96目标、3轮伤害总耗时 | 5.97ms | 6.05ms |

这是固定场景的采样，不是全流程最低帧率或所有硬件的性能保证。几何量有6000硬上限，地面查询共享32/tick预算，伤害每轮32目标并且每次施放最多512个唯一目标。视距、雾和地形仍会遮挡远景，不绕过光影的雾效果。

较新的Complementary Reimagined5.9.3也曾完成运行，但Oculus记录了上游新生物群系uniform警告；5.2.2作为本次明确验证的组合。第三方测试模组和光影仅放在忽略的测试目录，未作为本模组依赖或资源打包。

## 范围边界

测试输入使用真实游戏按键映射和自动脚本；联网为本机两客户端，不是公网延迟压测或多人服务器长期负载。八组并发使用收到的演出状态构造生产渲染负载，不表示启动了八个客户端。音频使用无输出OpenAL后端验证声道和触发，不声称完成了人工耳听校准。没有对全部整合包、光影、特殊模组方块或硬件作兼容保证。

本机原始证据位于忽略的build/fuga-combat-network-verified和build/fuga-combat-shader-framebuffer-fixed目录。公开截图见README及docs/images，原始存档、完整日志和本机路径未提交。
