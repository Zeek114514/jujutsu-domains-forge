# 五条/宿傩近战动作与命中反馈 — 本地1.11.0

## 行为与时序

- 五条：左苍拳→右苍拳→收尾拳。进阶形态以赫拳收尾，高专始终只苍拳。
- 宿傩：左右拳→近身斩击收尾；远处可准备普通斩击。普通斩击现在有7刻前摇，领域必中斩击不经过本套动作。
- 共享 `NpcAttackMotion`：三段拳的接触帧4/5/6刻，时长12/12/16刻；普通斩击接触7刻、时长16刻。服务端伤害和客户端动作使用同一时序。
- 原版方块手臂，蓄势、对侧护手、转腰带肩、踏步、接触与收势，无手指。源姿态恢复精确归零，外层皮肤同步。
- 真正成功伤害后才有短硬直和冲击粒子：普通4刻、收尾6刻，20刻保护间隔，避免围攻无限硬直。硬直取消当前近战并暂停主动近战启动；领域、紧急招式的特殊机制继续保留。
- 轻击尽量留住对手，赫拳和收尾提供更大击退。宿傩对满原版击退抗性的角色另加小幅有界位移，不修改血量、攻击/承伤倍率等战力参数。
- 常规术式不能打断尚未收完的拳，完整收势后可接术式。更换目标/间隔过长会重新起连招。宿傩斩击收势后在冷却期间仍会继续追击。
- 两只照片NPC、刷怪蛋、20%拴绳跟随互动保留。无下限通道升级8，领域通道14，客户端/服务端需同时更新1.11.0。
