# 灶·开：纯特效试作

版本 `1.1.0-preview.6`，Minecraft Java 1.20.1 / Forge 47.4.10+（47.x）/ Java 17。

## 怎么看

将 `unlimited-void-1.20.1-1.1.0-preview.6.jar` 放入测试实例的 `mods`，移走该实例中旧的本模组 JAR，重启游戏。多人客户端与服务端均需使用这份试作版本，不能混用 1.0.0。

左上角常驻显示按键和冷却状态，按 **O** 重置独立冷却（不打断正在播放的施放）。按 **H** 试放，按键可在游戏按键设置的原有「无量空处」分类中修改。

演出：手边聚火 → 像素火矢与火弓收束 → 发射并留下燃烧拖尾 → 接触方块/到达最远点时爆燃 → 冲击环、烟尘与余烬消散。蓄势时可转头瞄准，发射方向和落点在发射时由服务端确定。

蓄力段：火弓和火矢扩大到上一版的 3 倍，火弓全高约 5.7 格；脚下双环扩至半径 18 格，三股聚火旋涡升至约 12 格高，发射后用 10 tick 消散。第一人称采用更远的展示位置，便于看到放大的弓身。

新版蓄力已在独立 Forge 47.4.20 测试世界检查第一人称及外部观察视角截图，移除了贴脸的原版小火焰粒子。实机截图与日志保存在忽略的 `build/fuga-voice-final/`。

- 约 1.5 秒达到最大蓄力，在“Fuga”台词期间保持，约 2.7 秒发射。射程最多 64 格，飞行最多 12 tick，命中后演出约 6.6 秒。
- 大范围演出：地面火海半径 200 格（直径 400 格），主火柱高约 240 格，三道冲击波最远 300 格。同维度 768 格内的玩家可收到演出消息，实际可见内容仍取决于视距和地形遮挡。
- 独立 10 秒冷却，最多同时 8 个试作演出。U/J/K 与现有领域玩法保持原样；K 不重置火矢试作的独立冷却。
- 纯特效演出，使用用户选中的“Fuga”台词与同一来源的射出、爆燃音效，不造成伤害，不点燃或破坏方块，也不会创建爆炸实体。
- 普通地形深度遮挡保留。火焰使用原创 32×32、8 帧像素图集、交叉面片和粒子，不需要新增渲染前置。
- 对命中与可见范围的判定仅访问已加载路径。火海缓存最多 320 个地面采样，已加载位置贴地，未加载位置采用命中点水平面；不会为特效强行加载新地形。近/远景与多个同时施放使用固定数量面片和简化等级，不按覆盖方块数量生成实体。
- 死亡、退出、切换世界/维度及进入无量空处受控状态时会清理/取消相关演出。

建议找开阔测试地面，对准前方石墙观察落点。第一人称看手边聚火，第三人称或其他客户端看完整火矢与命中演出。

## 当前范围

这是独立特效试作，新增第三人称拉弓姿态、双股螺旋火矢、三道冲击环、分层火柱与近距离轻微镜头震动（受原版画面效果强度控制）。尚未接入御厨子粉尘引爆、伤害、第一人称双手动画或领域强化。演出不会改变原有领域逻辑；保留正式版以便回退。

本次使用 JDK 17 构建，通过 49 项时序、范围与边界检查及原有 15 项寻地几何检查。另外在 Forge 47.4.20 的独立测试目录、新建超平坦世界中实际运行，使用 H/O 按键映射验证了施放、施放中重置冷却、不重叠施放、自然结束、结束后重置冷却，并检查第一/第三人称、远景和火海内部截图。测试完成后自动退出，没有进入原存档。尚未验证多人、光影兼容或第一人称双手动画。

本地构建产物位于 `build/libs/`。本次没有上传 GitHub，也没有修改其他游戏实例或原存档。

已接入用户选择的第二个来源中的“Fuga”短片段，来源及处理见 [台词候选](FUGA_AUDIO_CANDIDATES.md)。语音预加载后随蓄力开始播放；取消施放或切换世界时停止。使用本地识别时间点编排，没有人工试听核验。

后半音效分为射出（约 0.60 秒）与爆燃余响（约 6.41 秒）：射出帧播放前者，达到实际命中点时停止前者并播放后者。支持不同飞行距离，分别定位在发射点和命中点，使用 96/384 格的衰减距离；分别提供字幕，遵循游戏音效及模组音量设置。移除了原版替代声，避免重复爆响。取消施放和切换世界会停止全部相关声道。

可选实机测试：用 `-PvisualTest=true jar` 构建带 `visual-test` 后缀的测试包，在独立的离线实例中加 JVM 参数 `-Duv.fugaTest=true` 启动。它会隐藏测试窗口、自动新建测试世界、触发按键、截图并退出；只应放入可丢弃的测试实例。普通构建不会包含该测试类。开发用例在 `tools/visualTest/`，本机大范围演出测试结果在忽略的 `build/fuga-district-test/` 和 `build/fuga-district-final/`。

## 开发入口

- `FugaTimeline`：共同的时序与边界。
- `server/FugaService`：服务端施放、冷却、已加载范围射线和取消。
- `network/DomainNetwork`：试放请求与客户端演出消息；协议为 12。
- `client/FugaClient` / `FugaRenderer`：按键、客户端状态、粒子与世界空间像素火焰。
- `tools/build_fuga_texture.py`：原创像素火焰图集生成器，仅依赖 Python 标准库。

修改后运行 `gradlew build`，其中会运行 `validateFuga` 和 `validateGround`。

后半音效实机验证（独立 Forge 47.4.20）：近落点的两个声道相隔 2 tick，较远落点相隔 5 tick，均仅触发一次；取消蓄力不会触发后续音效，播放中的爆燃长尾可被取消。日志和截图在忽略的 `build/fuga-sfx-final/`。导出文件另做了解码、时长、非静音和峰值检查，没有人工试听。
