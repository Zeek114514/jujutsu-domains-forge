# 1.12.0 发布验证

2026-11-08，本版包含此前本地玩法更新、灶·开重制、特级咒具OBJ模型、刀柄修订和游云三形态。历史记录按原测试包保留，以下是本次最终发布前复验。

## 生产构建与包核对

`cleanCompileJava build` 成功，共14278项规则检查。正常包不含VisualTest类。与固定QA包比较，271个生产class/asset/data及混入配置逐字节一致；META-INF发布说明/模组描述不属于玩法代码比较范围。最终公开下载包的SHA-256列在Release的SHA256SUMS.txt中。

## 咒具与三形态

独立新世界 `build/fuga-combat-plain-release-112-tools/host/console.log` 完成44项断言、无失败标记：

- 普通剑被无下限阻挡；天逆鉾穿透，打断苍，阻止立即重放，并使正在展开的领域进入消散过渡；2秒后防御恢复。
- 灵魂感知实际物品激活并同步客户端；未感知时受减伤，感知后对护甲/保护附魔/抗性IV目标完整造成26伤害；结束后穿透移除。
- 游云纯物理，普通22、力量II下56伤害；弱挥击更弱，正常耐久和无敌帧保留。
- 右键选择整棍并造成24伤害，生存模式实体触及4格；潜行削尖后16伤害、2.6攻速；有副手物品时拒绝或安全收回，原物品不丢失。
- 形态NBT保存/加载、各形态不同的非空OBJ模型通过。查看了修订刀柄、三形态展示及第一人称双刀实机画面。

## 最终双客户端与群战

独立回环TCP场景 `build/fuga-combat-network-release-112-network`：主端39项、远端4项断言，两端均有完成标记、无失败标记。覆盖原生NPC管理按钮及网络权限、红蓝对战快照与重置、跟随/待命、魔虚罗继承阵营、成长路线/咒力/解锁和保存/克隆、成长页面与三档粒子质量。

5波、每波16个NPC，1300个服务端tick（约65秒），每波包含实际灶·开；领域、术式和粒子数量上限检查通过。此次本机采样：平均tick2.43ms、P95为3.52ms、最大14.26ms，主客户端帧间隔P95为17.68ms。仅代表本机固定无光影场景，不推广为所有机器或公网延迟结论。
