# 灶·开 · v1.5.1

按 **H** 聚火、拉弓、吟唱并射出火矢，按 **O** 重置独立冷却。冷却10秒，按键可以修改。约1.5秒满弦、2.7秒射出，方向在发射时由服务端确定，最远64格，优先命中路径上的方块或可攻击生物。

## 普通爆燃

命中后默认在200格半径内造成火焰伤害，中心最大240点生命值，按距离衰减至边缘的60点；存活目标会短暂燃烧。普通爆燃检查方块遮挡，尊重护甲、抗火、创造/旁观模式和Forge伤害事件。每次施放每个目标最多结算一次。

施术者、队友和属于施术者的可驯服宠物受保护。完整的外部无量空处结界庇护其内部目标。粒子覆盖面积是视觉表现，不能据此判断伤害边界；伤害半径由服务端配置决定。只处理已加载目标，遮挡和保护规则仍然生效。

## 御厨子粉尘引爆

自己的御厨子成型后，持续斩击约5秒积累到100%粉尘，HUD会显示进度。火矢命中点位于该领域中时，消耗粉尘强化为领域范围的爆燃波，默认最大伤害480点，仍随距离衰减。

强化波从命中点向外扩散，最远范围取御厨子半径（默认200格），仅作用于自己的该领域范围内、已加载的目标。重叠领域的必中抵消和完整外部结界的庇护仍有效。其他玩家的粉尘不能被消耗。粉尘消耗后可继续积累。

粉尘采用临时玩法状态，默认关闭地形破坏时也可以积累。火矢本身不调用世界爆炸，不点燃或破坏方块；原有御厨子地形破坏开关保持独立且默认关闭。

## 动画与多人

第一人称显示自己的皮肤双臂：持弓、拉弦、满弦保持、射出回落；第三人称保留拉弓姿态。只修改显示，不更换或移走背包物品。

所有玩家使用服务端的施放开始时间、飞行时间和落点。后来进入范围的观察者会补收当前状态；重复包不会重播台词、射出声或爆燃。退出或切换维度时清理演出。客户端和服务端应同时更新到当前版本；本次保留协议13。

## 画面与性能

1.5.1默认启用独立ParticleEngine粒子，替换此前网格火焰：聚火火弓、火矢拖尾、命中后的上升火团、火星与烟尘。粒子具有独立速度、旋转、寿命和透明度变化，使用项目程序生成的柔边纹理。无需JVM预览参数。

每客户端最多4500个存活粒子、每tick新建300个；按并发量、距离和游戏粒子设置减少密度。取消、同施术者重新施法、演出淘汰和切换世界会清理对应粒子。地面查询每客户端tick共享32次预算，地形遮挡、雾与视距会影响可见范围。

服务端仍每4tick处理伤害，每轮最多扫描256个候选、命中32个目标、每次施放最多512个唯一目标，不强制加载区块。粒子改动没有调整伤害或音效。

## 配置

`config/unlimitedvoid-common.toml`：

```toml
fugaCombatEnabled = true
fugaDamageRadius = 200.0
fugaBaseDamage = 240.0
fugaDustDamage = 480.0
shrineTerrainDamage = false
```

首次升级会自动将未修改的旧默认组合16/32/80迁移为200/240/480，保留其他自定义组合；`fugaBalanceRevision`记录迁移状态。

将`fugaCombatEnabled`关闭可保留演出而关闭新的火矢伤害。已有燃烧按原版规则结束。
