# 灶·开 · v1.1.0

按 **H** 聚火、拉弓、吟唱并射出火矢，按 **O** 重置独立冷却。冷却10秒，按键可以修改。约1.5秒满弦、2.7秒射出，方向在发射时由服务端确定，最远64格，优先命中路径上的方块或可攻击生物。

## 普通爆燃

命中后默认在16格半径内造成火焰伤害，中心最大32点生命值，按距离衰减至边缘的8点；存活目标会短暂燃烧。普通爆燃检查方块遮挡，尊重护甲、抗火、创造/旁观模式和Forge伤害事件。每次施放每个目标最多结算一次。

施术者、队友和属于施术者的可驯服宠物受保护。完整的外部无量空处结界庇护其内部目标。远处的大范围火海和火柱仍是演出，不表示普通火矢自动伤害半径200格的全部实体。

## 御厨子粉尘引爆

自己的御厨子成型后，持续斩击约5秒积累到100%粉尘，HUD会显示进度。火矢命中点位于该领域中时，消耗粉尘强化为领域范围的爆燃波，默认最大伤害80点，仍随距离衰减。

强化波从命中点向外扩散，最远范围取御厨子半径（默认200格），仅作用于自己的该领域范围内、已加载的目标。重叠领域的必中抵消和完整外部结界的庇护仍有效。其他玩家的粉尘不能被消耗。粉尘消耗后可继续积累。

粉尘采用临时玩法状态，默认关闭地形破坏时也可以积累。火矢本身不调用世界爆炸，不点燃或破坏方块；原有御厨子地形破坏开关保持独立且默认关闭。

## 动画与多人

第一人称显示自己的皮肤双臂：持弓、拉弦、满弦保持、射出回落；第三人称保留拉弓姿态。只修改显示，不更换或移走背包物品。

所有玩家使用服务端的施放开始时间、飞行时间和落点。后来进入范围的观察者会补收当前状态；重复包不会重播台词、射出声或爆燃。退出或切换维度时清理演出。客户端和服务端必须同为1.1.0，网络协议已由12升级为13。

## 画面与性能

保留约400格直径火海、240格火柱与300格冲击波。可见范围受游戏视距、雾和地形遮挡影响。火海每个客户端tick共享32个地面查询预算，会重复采样以跟上新加载或被改变的地形；洞穴内从命中层向下取地面，半砖等使用实际碰撞面。

最多8个演出，按并发量、距离和粒子设置降低密度。每帧最多6000个四边形；伤害每4tick处理一轮，每轮最多32个目标、每次施放最多512个唯一目标，不强制加载区块。

## 配置

`config/unlimitedvoid-common.toml`：

```toml
fugaCombatEnabled = true
fugaDamageRadius = 16.0
fugaBaseDamage = 32.0
fugaDustDamage = 80.0
shrineTerrainDamage = false
```

将`fugaCombatEnabled`关闭可保留演出而关闭新的火矢伤害。已有燃烧按原版规则结束。

## 验证

本版进行了双客户端本机TCP联网测试、光影实际启用检查、复杂地形取样和并发演出/实体预算测试。完整记录见 [1.1.0验证记录](FUGA_COMBAT_VALIDATION.md)。测试组合不能代表所有光影和整合包；音频人工耳听逐帧校准没有作为已完成事项。
