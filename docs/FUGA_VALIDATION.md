# 灶·开预览版验证

记录日期：2026-10-26。版本 **1.1.0-preview.6**，开发依赖 Forge **47.4.10**，实际测试客户端 Forge **47.4.20**，JDK **17**。

## 构建与资源

- `build` 成功，49 项灶·开时序/范围/边界检查及 15 项寻地几何检查通过。
- 正常 JAR 不含 `VisualTest` 或几何检查入口类，实机测试代码只在显式 `-PvisualTest=true` 构建中启用。
- 三段音频分别预加载。新增射出/爆燃文件做了解码、非静音、时长、峰值与打包哈希核对。
- 射出约 0.60 秒，爆燃余响约 6.41 秒。来源、处理滤镜和哈希见 [音频清单](../requested_voice/fuga_manifest.json)。

## 独立世界实机测试

测试在离线账号的新建超平坦世界中自动触发游戏按键映射，没有进入原存档。它验证游戏内输入映射和实际渲染/音频声道，不等同于人工键盘操作或人工试听。

| 检查 | 结果 |
| --- | --- |
| H 施放、冷却与 HUD | 通过；台词期间满蓄力保持，随后发射 |
| O 重置冷却 | 通过；不会打断或重复当前施放 |
| 第一人称与外部观察视角 | 已截图检查火弓、聚火旋涡、远景火柱及火海内部 |
| 近距离射出/命中声 | 实际声道在测试 tick 93 / 95 启动，相隔 2 tick |
| 较远距离射出/命中声 | 实际声道在测试 tick 323 / 328 启动，相隔 5 tick |
| 空间定位与次数 | 射出声位于发射点，爆燃声位于命中点，每次各播放一次 |
| 蓄力中取消 | 台词停止，未触发后续射出或爆燃声 |
| 爆燃长尾取消 | 已在声道播放期间取消，先于自然结束停止 |

测试日志标记为 `FUGA_VISUAL_TEST_COMPLETE`，无 `FUGA_TEST_FAIL`。本机原始日志与截图保存在被 Git 忽略的构建目录，不上传存档、运行配置或完整原始日志。README 展示的图片为上述开发测试中的真实截图。
