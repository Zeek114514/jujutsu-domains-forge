# 魔虚罗 · 1.10.6

创造模式【咒术领域】栏使用魔虚罗生成蛋，也可 `/summon unlimitedvoid:mahoraga`。独立生成没有主人，正常选择怪物和五条作为目标，不主动攻击玩家、宠物或宿傩友军。空手右键显示1000点最大生命、当前生命和各项适应等级。

## 召唤与战斗

惠皮宿傩进入战斗10秒后，每2秒稀有判定中以1%概率请求召唤；每名召唤者一生最多成功一次，记录保存至存档。失败不消耗名额。附近128格最多8只绑定魔虚罗；只在已加载、无液体且有足够空间的地面召唤，不生成新区块或修改地形。

宿傩摆出原版方块手臂手势，魔虚罗从黑色影池用3秒升起，随后独立寻敌、拳击、剑斩和跃击。空闲时跟随主人，超出96格、主人死亡或离开世界时沉回影池，用1.5秒消失。短暂找不到加载中的主人有10秒宽限。主人NoAI时暂停主动战斗。生成蛋独立生成的实体没有这些主人退场限制。

模型基础身体约4格高（轮盘另计），腿和躯干拉长，保持窄腰宽肩；眼侧两对翼状结构由分层尖羽片连接而成；法轮水平悬在头顶，外围八个削角球状端头，短弯头冠保持在轮盘下方，黑色裤型、腰后白色飘带及胸前环状垂饰。模型具有巨型身体、分块肌肉、头部侧鳍、牙齿、腰带、右臂黑色缠布、剑刃及八握轮。轮盘每次适应平滑转动八分之一圈，伴随原创机械短音和少量金色粒子。

## 攻击动作

左拳重击有收肩、屈肘蓄力、踏步伸拳及收势；右臂斜斩通过转腰、带肩和剑臂斜向挥动发力。跃击时双臂举起、屈膝收腿，下降时下砸，落地后压低重心再站回。空间斩单独使用蓄势、前送和横向放出的动作。

新动作使用独立肘、膝关节，站立时抵消脚踝旋转并补偿腿长，减少脚底滑动；攻击手臂会参考注视俯仰。动画与服务端共用接触时刻，保留原伤害、攻击间隔和命中距离。

## 适应成长

每个现象每完成一级适应，累计体型增加5%。抗性满四级后，每再承受3次对应的有效命中、且距上次成长至少3秒（茈8秒），还能完成新一次成长；体型没有预设上限。抗性仍维持原有上限，成长单独累计。每次约1秒平滑成长，渲染、碰撞体、眼睛高度与近战触及范围一同变化；空间斩射程和生命上限不因体型额外增加。保存后体型由独立的累计成长次数恢复，旧存档从已有适应等级迁移，轮盘手动转动不会虚增体型。巨大体型会受通道空间限制，不穿墙或破坏地形。

## 逐步适应

物理、苍、赫、斩击、火焰、茈、无下限、无量空处分开积累。首次命中仍正常受伤，被直接打死就无法适应，不复活。每项抗性最多四级，对应该类伤害减少25%、50%、75%、90%，保留最低10%伤害；创造模式的强制清除等绕过无敌的伤害不受此保护。

每一级累计要求额外3次有效接触和3秒时间；茈每级累计需要额外8秒。相同现象的接触最快每5tick计数；单项两次升级至少2秒，全局轮盘升级至少间隔1秒，因此不会瞬间跳满。每次升级回复80点生命。非战斗受伤后等3秒，之后每2秒自然回复5点；NoAI关闭主动回复。

苍/赫牵引和击退随对应等级减弱，满级不再受其附加力量影响。无下限通过真实出手被阻挡来积累，满级后近战可命中五条，并解锁低概率、12秒冷却的空间斩（24格，受墙体遮挡）。无量空处在持续控制期间也能适应，满级解除行动控制；物理封闭结界仍然存在，不能直接穿壳。

生命、轮盘、主人、适应等级与累积时间支持NBT保存读取。完整关服重开存档、多台电脑联机及大规模性能尚未做本版验收。既有宿傩战力和领域修复沿用[1.9.1记录](NPC_BALANCE_VALIDATION.md)，本版实机范围见[攻击动作验证](MAHORAGA_ATTACK_ANIMATION_VALIDATION.md)、[无上限成长验证](MAHORAGA_GROWTH_VALIDATION.md)和[水平法轮验证](MAHORAGA_WHEEL_VALIDATION.md)，初版记录见[1.10.0验证](MAHORAGA_VALIDATION.md)。
