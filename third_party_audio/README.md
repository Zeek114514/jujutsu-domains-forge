Derived game sounds are trimmed, pitch-shifted, filtered, crossfaded, mixed and loudness-normalized by tools/build_audio.py. These CC0 base recordings are not Minecraft sounds. The two expansion clips are overwritten by the user-requested character voices; those are not CC0 and have separate provenance in requested_voice/README.md. Supplemental synthesized low tones are created by the build script. These derivative audio assets are also supplied under CC0-1.0. Main Java code remains MIT.

See downloads.json for exact public download URLs and SHA-256 hashes. Freesound page license snapshots remain in the author's working verification directory, not the mod JAR.

Since0.10.0, the three slash_wind and two slash_hit assets are also overridden by character-labelled Myinstants clips. Those five assets are not CC0; see requested_slashes/README.md. This CC0 declaration applies only to the listed Freesound recordings and derivatives that do not incorporate character clips.
